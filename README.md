# Сайт-портфолио Александры Итуниной

## Запуск

Открыть `Запустить сайт.command`, затем http://127.0.0.1:8765/.
Сборка фронтенда и npm не нужны. Сервер использует Python 3, Pillow и ReportLab; скрипт запуска настроен на установленную среду этого Mac.

## Структура

```text
index.html                     Разметка и тексты
assets/
  styles.css                   Стили и адаптивность
  app.js                       Карусель и анимация
  portrait.webp                Фотография
portfolio/
  01 Название проекта/         Порядок и название вкладки
    01.webp                    Слайды по порядку
  99 Отдельные слайды/
server.py                      Локальный сервер и API
scripts/export_pdf.py          Экспорт PDF на диск
output/pdf/                    Готовые PDF
AGENTS.md                      Правила работы
Как редактировать портфолио.md  Инструкция владельцу
```

Исходные PPTX в корне сохранены без изменений.

## Как работает

Браузер отдельно загружает HTML, CSS, JS и фото. `/api/portfolio` перечисляет изображения из папок, без встраивания их содержимого. Миниатюры используют ленивую загрузку. `/api/portfolio.pdf` создаёт PDF по запросу и кеширует результат до изменения файлов.

Папки имеют обязательный двухзначный префикс 01–99 и пробел; цифры не видны на сайте. Пустые папки и неподдерживаемые файлы пропускаются. Поддерживаются PNG, JPEG, WebP.

Локальный адрес привязан к 127.0.0.1. Облачная публикация не настроена. Для переноса проекта нужны файлы проекта вместе с assets и portfolio; одного index.html теперь недостаточно.
