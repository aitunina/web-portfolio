# Как редактировать портфолио

1. Откройте папку `portfolio` рядом с `index.html`.
2. Каждая подпапка — отдельная вкладка. Обязательный формат: `01 Название проекта`, `02 Другой проект`. Две цифры (01–99) и пробел задают порядок; на сайте цифры скрыты. Папки без такого префикса не отображаются. Для изменения очередности переименуйте префиксы. Для отдельных слайдов используйте `99 Отдельные слайды`.
3. Добавляйте внутрь изображения слайдов: PNG, JPG, JPEG или WebP. Вложенные подпапки, скрытые файлы и пустые папки не отображаются. PPTX и PDF сначала экспортируйте в изображения.
4. Для порядка слайдов называйте файлы `01.png`, `02.png`, `03.png`. Числа сортируются по порядку: 2 перед 10. Папки также сортируются по названиям.
5. Обновите страницу сайта. Новые файлы появятся, удаленные исчезнут. Переименование папки изменит название вкладки. Вкладка «Все работы» собирается автоматически.

Пример:

    portfolio/
      01 Новый проект/
        01.png
        02.jpg
      99 Отдельные слайды/
        01.webp

## Запуск

Дважды нажмите `Запустить сайт.command`, затем откройте http://127.0.0.1:8765/. Пока окно запуска открыто, сервер работает. Если сайт уже работает, повторно запускать не нужно. Для остановки нажмите Control+C в окне сервера.

Сервер доступен только на этом компьютере. Ничего не загружается в облако. Скрипт запуска использует установленный на этом Mac Python из среды Codex с Pillow и ReportLab.

## Скачать PDF

Кнопка «Скачать портфолио» в блоке портфолио создаёт PDF из актуальных папок, по одному изображению на страницу. Пропорции сохраняются; прозрачность выводится на белом фоне. Первая сборка после изменения файлов может занять несколько секунд.

## Ручное редактирование сайта

- `index.html` — тексты, разделы и ссылки.
- `assets/styles.css` — цвета, размеры, отступы и адаптивная верстка.
- `assets/app.js` — карусель, таймер и эффекты появления.
- `assets/portrait.webp` — фотография.
- `portfolio/` — проекты и слайды.
- `server.py` — локальный сервер, чтение папок и PDF.

После изменения файлов обновите страницу. После изменения `server.py` перезапустите сервер. Для работы портфолио открывайте сайт через localhost; открытие HTML двойным щелчком больше не заменяет сервер.

Для сохранения отдельного PDF на диске запустите `Сохранить портфолио PDF.command`. Файл появится в `output/pdf`. Изображения и PDF больше не встраиваются в HTML.
