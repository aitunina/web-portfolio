# Как редактировать портфолио

1. В папке `portfolio` создайте подпапку вида `01 Название проекта`.
2. Первые две цифры (01–99) и пробел обязательны. Они задают очередность, но не видны во вкладках. Для отдельных слайдов используйте `99 Отдельные слайды`.
3. Внутри разместите PNG, JPG, JPEG или WebP: `01.png`, `02.png`, `03.png`. PPTX и PDF сначала экспортируйте в изображения. Пустые папки и другие форматы не отображаются.
4. Локально запустите `Собрать портфолио.command`, затем откройте `index.html` двойным щелчком. Сервер запускать не нужно.
5. Для сайта на GitHub отправьте изменения в `main`. GitHub Actions самостоятельно создаст данные и PDF перед публикацией.

Кнопка скачивания открывает `downloads/portfolio.pdf`. Его пересоздаёт та же сборка из текущих изображений, по одному слайду на страницу.

Для правки текстов используйте `index.html`, оформления — `assets/styles.css`, логики — `assets/app.js`. После изменения портфолио нужна сборка, после изменения текстов и стилей локально достаточно обновления страницы.

Настройка GitHub Pages и структура проекта описаны в README.md.
