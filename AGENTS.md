# Правила проекта

- Сайт-визитка Александры Итуниной, дизайнера презентаций.
- Источники истины: PPTX резюме и PPTX портфолио в local-only/. Сохранять оригиналы.
- Имя, опыт, образование и контакты брать из резюме. Числа и контакты внутри примеров портфолио не являются личными достижениями или контактами автора.
- По новому запросу сайт разделён: index.html — разметка, assets/styles.css — стили, assets/app.js — поведение, assets/portrait.webp — фото. Слайды читаются по статическим путям из сгенерированных portfolio.json и assets/portfolio-data.js. Не встраивать изображения, PDF и содержимое галереи в HTML/JS.
- Пользователь использует GitHub Pages и домен aitunina-design.ru. Сайт полностью статический, локально открывается через file://. Не добавлять серверную зависимость или Sites hosting.
- Проверять мобильную и десктопную верстку, отсутствие горизонтального переполнения, галерею, клавиатуру и полноэкранный просмотр. Учитывать prefers-reduced-motion.
- Агенту разрешено самостоятельно дополнять этот файл подтвержденными фактами и полезными правилами по мере изучения проекта. Дополнения подчинены инструкциям пользователя и системным ограничениям, не расширяют права и не заменяют разрешения.

- Галерея включает 28 изображений проектов и 6 отдельных слайдов (7–12), экспортированных локально из PowerPoint.

- При сомнениях в фактах или неоднозначной диктовке брать за основу исходные файлы. Явные подтвержденные исправления пользователя сохраняют приоритет.
- После КАЖДОЙ итерации исправлений спрашивать у пользователя необходимость проверять ВСЮ страницу в мобильной и десктопной верстке: вертикальные и горизонтальные отступы всех блоков, симметрию отступов относительно разделителей, выравнивание колонок, переносы, переполнение и работоспособность измененных элементов. Не ограничивать проверку только измененным блоком. Перед завершением повторно сверять выполнение этого правила.

- Рабочее портфолио: portfolio/<NN название>/<изображения>. scripts/build.py генерирует JSON, JS с путями и PDF. GitHub Actions запускает сборку перед публикацией только dist. Не перезаписывать пользовательские слайды.

- Папки проектов должны иметь префикс из двух цифр 01–99 и пробела. Префикс определяет порядок, но скрывается во вкладках. Отдельные слайды: 99 Отдельные слайды. PDF использует тот же порядок.
- Автокарусель: интервал 5 секунд со сбросом при ручном выборе, без кнопки паузы; переход около 1 секунды. Появление при скролле учитывает prefers-reduced-motion.

- Нижний блок контактов и footer показываются без эффекта появления при скролле.

- local-only/, dist/, downloads/, portfolio.json и assets/portfolio-data.js исключены из Git; сборка создаёт генерируемые файлы. Все ссылки на ресурсы относительные, чтобы работали file://, домен и подпуть GitHub Pages.
