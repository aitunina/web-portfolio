# Правила проекта

- Сайт-визитка Александры Итуниной, дизайнера презентаций.
- Источники истины: PPTX резюме и PPTX портфолио в local-only/. Сохранять оригиналы.
- Имя, опыт, образование и контакты брать из резюме. Числа и контакты внутри примеров портфолио не являются личными достижениями или контактами автора.
- По новому запросу сайт разделён: index.html — разметка, assets/styles.css — стили, assets/app.js — поведение, assets/portrait-pistachio.png — фото. Слайды читаются по статическим путям из сгенерированных portfolio.json и assets/portfolio-data.js. Не встраивать изображения, PDF и содержимое галереи в HTML/JS.
- Пользователь использует GitHub Pages и домен aitunina-design.ru. Сайт полностью статический, локально открывается через file://. Не добавлять серверную зависимость или Sites hosting.
- Проверять мобильную и десктопную верстку, отсутствие горизонтального переполнения, галерею, клавиатуру и полноэкранный просмотр. Учитывать prefers-reduced-motion.
- Агенту разрешено самостоятельно дополнять этот файл подтвержденными фактами и полезными правилами по мере изучения проекта. Дополнения подчинены инструкциям пользователя и системным ограничениям, не расширяют права и не заменяют разрешения.
- Делать коммит и пуш после каждого выполнения, если это явно не запрещено в инструкции к команде. Выводить в конце каждого сообщения хэш коммита, если он был

- Количество слайдов определяет содержимое portfolio/; на момент обновления дизайна — 33 слайда в 7 папках.

- При сомнениях в фактах или неоднозначной диктовке брать за основу исходные файлы. Явные подтвержденные исправления пользователя сохраняют приоритет.
- После КАЖДОЙ итерации исправлений проверять ВСЮ страницу в мобильной и десктопной верстке: вертикальные и горизонтальные отступы всех блоков, симметрию отступов относительно разделителей, выравнивание колонок, переносы, переполнение и работоспособность измененных элементов. Не ограничивать проверку только измененным блоком. Проверка уже авторизована пользователем, повторно спрашивать разрешение не нужно. Перед завершением повторно сверять выполнение этого правила.

- Рабочее портфолио: portfolio/<NN название>/<изображения>. scripts/build.py генерирует JSON, JS с путями и PDF. GitHub Actions запускает сборку перед публикацией только dist. Не перезаписывать пользовательские слайды.

- Папки проектов должны иметь префикс из двух цифр 01–99 и пробела. Префикс определяет порядок, но скрывается во вкладках. Отдельные слайды: 99 Отдельные слайды. PDF использует тот же порядок.
- Автокарусель: интервал 5 секунд со сбросом при ручном выборе, без кнопки паузы; переход 1 секунда; прокрутка миниатюр — тоже 1 секунда. При открытом полноэкранном просмотре автопереключение остановлено, после закрытия новый отсчёт 5 секунд. Появление при скролле учитывает prefers-reduced-motion.

- Нижний блок контактов и footer показываются без эффекта появления при скролле.

- local-only/, dist/, downloads/, portfolio.json и assets/portfolio-data.js исключены из Git; сборка создаёт генерируемые файлы. Все ссылки на ресурсы относительные, чтобы работали file://, домен и подпуть GitHub Pages.

- все файлы необходимые для функционирования сайта сразу добавлять git add, если файл нужен только локально размещать в одной из игнорируемых папок

- Утверждённый дизайн: единый фон #17191a, светлые заголовки #f0f2e8, фисташковые акценты #c7d99d. Не выделять «Обо мне» другим фоном. Сохранять полное содержимое и поведение галереи при изменениях оформления.
- Новое фото: assets/portrait-pistachio.png. Оригинал сохранён в local-only/source-photos/portrait-original.webp. Telegram @aviita был убран пользователем при ручной правке; не возвращать без нового запроса.
- Логотипы мероприятий хранятся в assets/events/, источники — в ASSET-SOURCES.md. Не представлять участие в подготовке презентаций как партнёрство или победу в премии.

- Перед выбором навыков читать SKILLS.md: применять подходящий навык по типу задачи, сверяя его наличие с актуальным каталогом сессии. Не запускать весь список автоматически.

- Проверки вёрстки подтверждать измерениями в браузере, а не только CSS: мобильные стрелки имеют равные ширину и высоту; боковые подписи контактов симметричны границам контейнера; интервалы от разделителя до первой строки, между строками и до нижнего разделителя измеряются по DOM. Для портрета отдельно проверять совпадение фона изображения и страницы на десктопе и мобильном.
- Галерею проверять после загрузки шрифтов/изображений, переключения вкладки и изменения окна; отдельно проверять dialog в открытом состоянии, размеры картинки и доступность управляющих кнопок. Скроллбар вкладок и миниатюр скрыт, прокрутка сохранена.
- Исправлять компонент целиком: не накапливать противоречащие друг другу правила одного свойства по медиазапросам. В отчёте отличать автоматические проверки геометрии от визуального осмотра скриншотов.

- Портрет: использовать PNG с настоящим alpha из резюме, без повторной генерации лица и фона; фисташковый пиджак перекрашен точечно с явно полученным разрешением пользователя на локальный скрипт. Все правила .portrait/.portrait-wrap собраны в одном блоке. Свечение строится drop-shadow по alpha силуэта и плавному низу на .portrait-wrap; не заменять его овалом/прямоугольником и не обрезать родительским overflow. Не добавлять старые mask/mix-blend-mode/overflow-переопределения. Проверять края на реальном фоне; мягкость низа — отдельно на масштабе 100%.

- Текущий портрет — lossless PNG 853×1280 с неизменённым исходным alpha. Перекраска пиджака локальным скриптом разрешена пользователем; сохранять пиксели лица и области вне маски. Исходник assets/portrait-original.png нужен для последующего редактирования, но не копируется в dist. Не заменять фотографию генерацией ради изменения одного цвета.

- Полноэкранный счётчик центрировать отдельно от счётчика галереи; проверять центр текста, симметрию стрелок и вертикальную середину нижнего ряда относительно окна. Высококачественная копия фисташкового портрета: local-only/source-photos/portrait-pistachio-master.png (не Git).
