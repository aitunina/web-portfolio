# Проверка перед публикацией

```sh
python scripts/build.py --output dist
python tests/build_test.py
npm ci
npx playwright install chromium webkit
npm test
SITE_ROOT=dist npm test
```

Python использует `requirements-build.txt`. Node нужен только для тестов, сайт остаётся статическим. В Actions проверяется именно `dist` до публикации. Для Linux установка браузеров: `npx playwright install --with-deps chromium webkit`.

## Что проверяется автоматически

- 17 размеров: 1920×1080, 1440×900, 1366×768, 1280×800, 1101×800, 1100×800, 1024×768, 768×1024, 761×900, 760×900, 601×900, 600×900, 430×932, 390×844, 360×800, 320×740, 844×390. В Chromium и WebKit; на телефонах — эмуляция touch и плотности 2×.
- Вся страница: горизонтальное переполнение, равные внешние поля, симметричные вертикальные отступы разделов, совпадение вертикальных разделителей трёх колонок, одинаковый фон, цвет заголовков, загрузка и единое семейство шрифтов.
- Контакты: симметрия боковых подписей на десктопе, равенство четырёх вертикальных интервалов на телефоне, почта и телефон в одном ряду. Расстояние от миниатюр до разделителя футера ограничено общим интервалом.
- Фото: PNG без потери исходного разрешения, неизменные alpha и пиксели лица/волос в верхней области, отсутствие пересжатия при сборке, правильные пропорции и достаточное разрешение для 2×. Свечение не обрезается родителями, маска низа присутствует, режим смешивания не меняет лицо.
- Галерея: круглые стрелки, видимость активной миниатюры, вкладки, клавиатура, возврат фокуса, секундные переходы основного изображения и миниатюр. Автопереход через 5 секунд, сброс после ручного выбора, пауза при просмотре, новый отсчёт после закрытия.
- Просмотр: центр именно текста счётчика, симметрия стрелок, вертикальное выравнивание нижнего ряда, границы изображения и кнопок, изменение размера открытого окна. Проверка фокуса допускает переход к интерфейсу браузера, но не к элементам страницы за диалогом.
- Reduced motion: разделы остаются видимыми, слайды сменяются без анимации. Контакты и футер не получают эффект появления.
- Синтезированный сенсорный свайп в Chromium. WebKit проверяет геометрию и управление; это не тест на физическом iPhone.
- Папки и порядок берутся из содержимого `portfolio/`, число слайдов не зафиксировано в тесте. При единственном слайде проверки автопереходов пропускаются.
- HTTPS и подпуть Pages проверяются через перехват запросов к тестовому домену, без запуска сервера: JSON, резервный JS при сетевой ошибке, загрузка PDF, относительные пути.
- Все публичные ссылки соответствуют хешу содержимого; замена файла меняет URL, изменение только даты — нет. Оригиналы, исходники и код тестов не попадают в `dist`.
- Контроль чувствительности: временно вносятся обрезание свечения, неверный фон и неравный отступ. Проверки обязаны обнаружить каждую из этих ошибок; затем временные стили удаляются.

## Что требует визуального осмотра

Скриншоты всей страницы, hero, мероприятий, галереи и просмотра сохраняются в `output/qa/<движок>/`. `report.json` содержит измерения; `failure.json` — причину сбоя и уже выполненные проверки. В Actions эта папка сохраняется отдельным артефактом на 7 дней.

После правок фото смотреть hero на десктопе и телефоне при 100% масштабе: резкость лица, ореол вокруг волос, правый край свечения, плавность низа. Числовой тест наличия маски сам по себе не доказывает красивый градиент. Дополнительно осматривать полную страницу, переносы заголовков и подписи, выбранный и наведённый элементы, открытый просмотр.

Реальные Safari/iPhone, настройки увеличения текста ОС, произвольные расширения и все существующие экраны этим набором не покрыты. WebKit — проверка движка, а не запущенного пользовательского Safari. Перехваченные HTTPS-запросы не воспроизводят реальный HTTP-кеш: его проверять по заголовкам публичного домена и состоянию деплоя. Не сообщать, что тесты доказали отсутствие всех возможных дефектов.

## Адресный повтор

После общего прогона исправлять найденное одним пакетом и повторять общий прогон один раз. Отдельный сбой сценария можно диагностировать через `QA_PHASE=behavior npm test` или `QA_PHASE=layout npm test`; `QA_BROWSERS=webkit` ограничивает движок. `QA_CHROME=/абсолютный/путь/к/Chrome` позволяет использовать установленный Chrome. Эти сокращённые запуски не заменяют итоговый полный прогон.

При изменении согласованного дизайна сначала проверить, изменилось ли требование. Не ослаблять геометрические допуски ради зелёного результата. Не принимать новые эталонные изображения автоматически.
