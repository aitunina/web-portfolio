# Выбор навыков для проекта

Этот файл — проектные правила выбора навыков, а не устанавливаемый пакет Codex. Читать его по ссылке из AGENTS.md перед выбором навыков. Он не запускает инструменты сам: агент выбирает подходящий навык и читает его актуальный SKILL.md.

## Как выбирать

Сначала определить результат задачи и проверить актуальный список доступных навыков в сессии. Использовать минимальный подходящий набор; не читать и не запускать весь каталог. Явно названные пользователем навыки учитывать обязательно. При первом применении кратко сообщать о выборе. Текущие инструкции пользователя и фактическое устройство проекта важнее шаблонов навыка.

Названия ниже сверены с каталогом сессии 13 сентября 2026 года; локальные дизайнерские навыки дополнительно проверены в ~/.codex/skills. Пути плагинов и версии могут меняться — брать их из текущего каталога, не хранить здесь абсолютные пути конкретного компьютера.

## Проверка результата

После каждой итерации вёрстки выполнять проверку всей страницы согласно AGENTS.md: десктоп и мобильный экран, отступы, переносы, границы колонок, отсутствие переполнения. Для изменений карусели проверять стрелки, миниатюры, просмотр, клавиатуру, секундные анимации, паузу автопрокрутки в просмотре и reduced motion. Навык не отменяет эти проектные проверки и не даёт разрешение на публикацию или отправку сообщений.

Для повторяющихся замечаний об отступах использовать impeccable/reference/layout.md и craft-floor.md: сначала определить контейнеры и общие интервалы, затем проверить фактические bounding boxes. В одном прогоне собирать всю страницу, hero, галерею и открытый dialog на десктопе и мобильном. Автотест «нет переполнения» не подтверждает симметрию, одинаковые интервалы или отсутствие рамки растрового изображения — эти свойства проверять отдельно. Достаточно исходного комплексного прогона и одного подтверждающего после исправлений; дальнейшие прогоны только для конкретного оставшегося дефекта.
